# VIX One

Приложение для синхронизации одной папки между устройствами через вечное хранилище Vix Hub.

## Возможности
- Динамический base URL из Firebase RTDB
- Загрузка файлов (POST /upload)
- Список файлов (/images)
- Скачивание (/image/<id>)
- Ключ-значение БД (/db/...)
- Выбор папки через SAF
- Тёмный Material 3 интерфейс

## Сборка
APK собирается автоматически через GitHub Actions.
