# VIX One — Чат с шифрованием

Telegram-подобный чат на базе Vix Hub.

## Возможности
- Личный архив
- Создание и вступление в группы
- Добавление участников по тегу
- Шифрование сообщений (AES-GCM)
- Отправка текста (файлы — в следующих версиях)

## Сборка
APK собирается автоматически через GitHub Actions.
